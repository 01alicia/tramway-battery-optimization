# Tramway Battery Optimization

This project studies the integration of onboard battery storage in a DC tramway system.

The objective is to **optimize battery capacity and control strategy** to balance:

- Energy storage cost (battery capacity)
- Electrical performance (voltage drop)

## Key Features

- Physical modeling of a tramway electrical system
- Time-domain simulation
- Rule-based battery control
- Multi-objective optimization (Monte Carlo, genetic algorithm)
- Pareto front analysis
